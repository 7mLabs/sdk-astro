# Hình ảnh tài liệu Astro / Astro documentation artwork

Dùng logo đầy đủ PNG do chủ dự án chọn, cùng tài sản nhận diện đã dùng cho Numerology. Bản thu nhỏ giữ nguyên tỷ lệ, màu và nền trong suốt; không sửa tệp gốc. Logo nhận diện nằm riêng với vòng tròn minh họa chức năng. Vòng tròn không phải lá số thật, kết quả kiểm thử hay chứng nhận độ chính xác.

Banner và sơ đồ có bản tiếng Việt/English, sáng/tối; huy hiệu có hai theme. README chọn bằng `picture` và `prefers-color-scheme`, mặc định sáng. Nền toàn trang GitHub do GitHub điều khiển. SVG chỉ nhúng PNG logo, không script, foreignObject, font hay ảnh tải từ mạng. `assets/readme-banner.svg` ở gốc là bản English sáng để giữ các liên kết ảnh cũ.

The full owner-selected 7mlabs logo is reused without redrawing. Theme-aware SVG artwork is self-contained. Zodiac geometry is illustrative, not a calculated chart or accuracy badge. Property badges describe the project; actual validation is linked from the release evidence.
